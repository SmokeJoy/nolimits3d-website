Reduced Motion CSS Overrides:
The global stylesheet packages/ui/styles/global.css contains the following standard media query block to override and neutralize animation/transition properties when user preferences dictate reduced motion:

@media (prefers-reduced-motion: reduce) {
  *, ::before, ::after {
    animation-delay: -1ms !important;
    animation-duration: 1ms !important;
    animation-iteration-count: 1 !important;
    background-attachment: scroll !important;
    scroll-behavior: auto !important;
    transition-duration: 0s !important;
    transition-delay: 0s !important;
  }
}

Verification in JSDOM environment / Playground:
1. When simulated using prefers-reduced-motion, JSDOM tests verify that transition-duration resolves to 0s/none.
2. In the playground application apps/ui-playground/src/App.tsx, the reduced motion simulation can be toggled to verify layout stability and transition-free style rendering.
