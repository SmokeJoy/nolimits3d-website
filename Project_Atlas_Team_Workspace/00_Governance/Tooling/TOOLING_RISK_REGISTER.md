# Tooling Risk Register

| Risk | Impact | Mitigation |
|---|---|---|
| Excessive permissions granted | High | Enforce Tool Permission Matrix. |
| Tool duplicates authoritative source | Medium | Linear does not replace Bible/Playbook. |
| Cost/licensing conflicts | Medium | Stick to approved Hobby/Free tiers initially. |
| Vendor lock-in | High | Avoid proprietary workflows. Keep code agnostic where possible. |
