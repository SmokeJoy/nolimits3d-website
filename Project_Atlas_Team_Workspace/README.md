# Project Atlas Team Workspace

Canonical operational workspace for Gemini coordination, shared memory, registers, evidence, handoffs and temporary delete quarantine.

## Canonical areas

- `00_Governance/`: operational rules and tooling governance;
- `01_Shared_Memory/`: current state and decisions;
- `04_Planning/`: milestone, sprint, blocker and cleanup registers;
- `05_Evidence/`: test/review evidence indexes;
- `06_Handoffs/`: current contract and archived handoff metadata;
- `07_Reports/`: governed reports;
- `99_DELETE_QUARANTINE/`: uncertain deletion candidates only.

This workspace does not replace the Documentation Bible, Development Playbook or Development Blueprint.
