# Admin — Wireframe Specification

> **Document ID:** DOC-UX-010  
> **Versione:** 0.95.3  
> **Stato:** In Review  
> **Owner:** UX Design  
> **Ambito autorevole:** definito dall’Owner Document Registry; eventuali riferimenti prevalgono sui riepiloghi locali.


## Desktop
Sidebar, command/search, overview, code attività, tabelle, editor, audit e Jarvis. Layout a griglia con gerarchia visiva ampia, CTA persistente solo quando non invasiva e contenuti secondari progressivi.

## Tablet
Riduzione colonne, filtri in drawer, touch target ≥ 44×44 CSS px, preview e tabelle adattive.

## Mobile
Ordine dei contenuti basato sull'intento; CTA primaria visibile presto; moduli a una colonna; media ottimizzati; nessun hover-only.

## Stati da disegnare
Loading, empty, error, partial data, offline/retry, permission denied, success e contenuto lungo.

## Flusso
Ingresso → comprensione → prova/riscontro → azione → conferma → prossima azione.

## Criteri
Prototipo navigabile per tre viewport; annotazioni componenti; contenuti realistici; verifica keyboard e screen reader sui flussi core.

## NoLimits Command Center

Desktop: rail moduli, header con ricerca/azioni, priority queue, metriche, sistema e pannello Jarvis privato. Tablet: navigation drawer e code impilate. Mobile amministrativo: triage e approvazioni essenziali, senza scene 3D pesanti. Ogni azione proposta da Jarvis mostra modalità, impatto, record coinvolti, rischio e conferma.
