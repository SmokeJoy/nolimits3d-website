# Global User Flows

> **Document ID:** DOC-UX-002  
> **Versione:** 0.95.3  
> **Stato:** In Review  
> **Owner:** UX Design  
> **Ambito autorevole:** flussi end-to-end, branching e recovery tra superfici pubbliche e operative.

## Flusso di ingresso

```text
Ingresso
  → comprensione promessa
  → “Cosa vuoi realizzare oggi?”
  → selezione intento o navigazione libera
  → prova pertinente
  → processo/limiti
  → CTA coerente
  → conferma e prossimo passo
```

## Mappa intenti

| Intento | Destinazione primaria | Fallback |
|---|---|---|
| Ho un pezzo da realizzare | ricambi / richiesta progetto | contatto diretto |
| Ho un’idea | brief guidato / progettazione | esempi e FAQ |
| Cerco un regalo unico | catalogo / personalizzazione | Ispirati |
| Ho un progetto professionale | landing B2B / brief | casi studio |
| Voglio lanterna o HueForge | configuratore / Arte in stampa 3D | galleria |
| Voglio vedere cosa realizzate | Realizzazioni | Catalogo/Ispirati |

## Funnel

### Progetto o servizio
Intento → prova → processo → richiesta → qualificazione → Andrea/operatore → preventivo → accettazione.

### Prodotto standard
Intento → Catalogo → prodotto → carrello → checkout → conferma.

### Lanterna catalogo
Intento → configuratore → validazione → prezzo/range → carrello o richiesta.

### Lanterna personale
Spiegazione → upload 1–4 foto → richiesta → anteprima entro massimo 48 ore come SLA candidato → revisione → preventivo → pagamento.

### HueForge
Scoperta artistica → galleria → opera/prodotto → acquisto oppure richiesta personalizzata.

### Professionale
Landing → casi → capacità/limiti → brief → contatto → preventivo.

### Evento
Calendario → scheda → luogo/data/condizioni → incontro/acquisto.

## Timeline “Come nasce il tuo progetto”

Idea → analisi → progettazione → realizzazione → controllo → consegna. Il sistema mostra la variante applicabile e non promette progettazione o anteprima quando il prodotto standard non la richiede. Assistenza usa triage → diagnosi → proposta → intervento/supporto → verifica → chiusura.

## Regole globali

- stato, prossimo passo e responsabilità sempre visibili;
- nessuna conversione dipende da 3D, video, AI o personalizzazione;
- recupero bozza nei flussi lunghi;
- consenso separato per analytics/personalizzazione;
- canale “Parliamone” mostrato solo se operativo;
- laboratorio privato: appuntamento/consegna solo secondo modalità documentate;
- Jarvis non appare in alcun flusso cliente.
