## Case study template

Contesto → obiettivo → vincoli → decisioni → materiale/processo → iterazioni → risultato → limiti/learnings → gallery → CTA. Metriche sono usate solo se documentate.

## Publication

Customer/company naming è opt-in. Per casi anonimi si rimuovono dettagli re-identificanti. File STL e disegni non sono scaricabili salvo autorizzazione.

## Acceptance

Provenance media, claims verificati, privacy check, internal link e schema appropriato, responsive gallery e alt contestuali.
