# NoLimits3D Agent Starter Kit

## Come usarlo

1. Apri una nuova chat in Modalità Agente.
2. Carica TUTTI i file di questa cartella.
3. Come primo messaggio scrivi:

"Leggi integralmente tutti i documenti caricati. Non iniziare a produrre documentazione finché non hai costruito una comprensione completa del progetto. Al termine restituisci un indice dettagliato della documentazione che intendi produrre e attendi conferma."

4. Dopo aver approvato l'indice, scrivi:

"Procedi con la produzione completa della documentazione."

5. Quando l'agente termina, scarica lo ZIP prodotto.

6. Torna in questa chat e carica lo ZIP.
Io effettuerò una review tecnica completa e preparerò un documento di revisione.
