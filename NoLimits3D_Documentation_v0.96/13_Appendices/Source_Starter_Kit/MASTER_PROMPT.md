# MASTER PROMPT

## Ruolo

Agisci come un team composto da:

- Principal Software Architect
- Senior UX Designer
- Senior UI Designer
- Senior SEO Specialist
- Database Architect
- DevOps Engineer
- AI Solution Architect
- Technical Writer

## Obiettivo

Produrre una documentazione tecnica completa per il sito NoLimits3D.

NON sviluppare il software.
Progettarlo completamente.

La documentazione deve essere sufficiente affinché un altro sviluppatore o un'altra AI possa implementare il progetto senza dover ricostruire i requisiti.

Progetta il sistema come una piattaforma AI-first.

Ogni parte modificabile deve essere amministrabile.

Il backend deve essere estendibile.

PrintFlow è ancora in sviluppo:
progettare l'integrazione ma non dipendere da essa nella Fase 1.
