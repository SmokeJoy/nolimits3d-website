# Contesto progetto

NoLimits3D è un laboratorio di stampa 3D.

Offre:
- prodotti propri
- servizi di stampa 3D
- modellazione
- assistenza stampanti
- configuratore lanterne HueForge
- blog
- portfolio
- eventi e fiere
- area clienti
- newsletter

Laboratorio privato non aperto al pubblico.

Vendita diretta durante fiere ed eventi.

PrintFlow avrà una pagina "In arrivo" nella Fase 1.

Fase 2:
preventivatore STL con chat AI, slicing, integrazione PrintFlow, revisione umana finale.

Dashboard Admin con Jarvis per gestione contenuti.
